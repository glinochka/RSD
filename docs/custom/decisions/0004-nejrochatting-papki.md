## Проблема

Нейрочаттинг не запускался на выбранных папках и писал, что в них нет чатов. Счётчик групп смотрел только последние четыреста строк папки. Если сверху лежали каналы, группы ниже он не видел. Нейрокомментинг на тех же папках каналы находил.

## Решение

Группы для нейрочаттинга считаются по всей выбранной папке. Канал в этот счётчик не входит. Плашка «в выбранных папках нет чатов» остаётся только когда групп во всех выбранных папках нет. Нейрокомментинг по-прежнему берёт каналы и не берёт группы.

## Что сделали

Счётчик «гр.» и проверка запуска читают все активные цели папки с типом чата. Пустой тип остаётся у каналов. В пул нейрочаттинга из смешанной папки попадает группа, в пул нейрокомментинга — канал.

## Что сознательно не делали

Паузы, набор прокси, контент-завод и Масштаб не менялись. Список чатов на экране по-прежнему показывает последние четыреста строк, на запуск по папке это не влияет.
