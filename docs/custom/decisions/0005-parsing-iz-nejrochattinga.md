## Проблема

Из нейрочаттинга нельзя было собрать юзеров из чатов, где аккаунты уже сидят, и сложить их в одну папку для масслукинга и масспрайминга.

## Решение

На экране нейрочаттинга кнопка «Парсинг юзеров». Окно показывает настройки уже существующего парсера юзеров. Запуск ставит в очередь тот же проход парсера. Берутся аккаунты этой задачи и только группы, где они уже состоят. Каналы не парсятся, вступления нет. Юзеры одного запуска пишутся в одну папку. Её видно в выборе папок масслукинга и масспрайминга.

## Что сделали

Кнопка и окно на экране нейрочаттинга. Запуск вызывает `run_parser_pass` с теми же лимитами. Настройки окна пишутся в сохранённый парсер, а флаг «только уже вступившие» живёт только у этого запуска и обычный парсер не переключает.

## Что сознательно не делали

Второй парсер не писали. Паузы, набор прокси, счётчик групп по всей папке, контент-завод и Масштаб не менялись. Чат, где аккаунт ещё не состоит, этот запуск не парсит.
