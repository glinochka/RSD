# Frontend Refactoring - RSD Platform\n\nПолный профессиональный рефакторинг frontend части приложения RSD.\n\n## 📋 Что было сделано\n\n### 1️⃣ **Архитектура и Конфигурация**\n\n#### Created:\n- **`config/environment.js`** - Централизованная конфигурация окружения\n- **`config/constants.js`** - Все константы приложения (маршруты, сообщения, правила валидации)\n- **`.env.example`** - Шаблон переменных окружения\n\n**Преимущества:**\n- Легко управлять конфигурацией для разных окружений\n- Все константы в одном месте\n- Меньше hardcoded значений в коде\n\n---\n\n### 2️⃣ **API Service Layer**\n\n#### Created:\n- **`services/apiClient.js`** - Улучшенный API клиент с:\n  - Автоматической подхваткой токена\n  - Обработкой ошибок\n  - Логированием в разработке\n  - Перенаправлением на авторизацию при 401\n\n- **`services/authService.js`** - Сервис для всех операций с авторизацией\n- **`services/agentService.js`** - Сервис для работы с агентами (включая загрузку файлов)\n\n**Преимущества:**\n- Разделение логики API запросов от компонентов\n- Единая обработка ошибок\n- Легко модифицировать API запросы\n\n---\n\n### 3️⃣ **Custom Hooks**\n\n#### Created:\n- **`hooks/useAsync.js`** - Управление асинхронными операциями\n- **`hooks/useForm.js`** - Управление состоянием формы с валидацией\n- **`hooks/useLocalStorage.js`** - Синхронизация состояния с localStorage\n- **`hooks/useFetch.js`** - Удобный fetch с кешированием\n- **`hooks/index.js`** - Централизованный экспорт\n\n**Преимущества:**\n- Переиспользование логики\n- Меньше кода в компонентах\n- Легче тестировать\n\n---\n\n### 4️⃣ **Context & State Management**\n\n#### Created:\n- **`context/AuthContext.jsx`** - Глобальное управление аутентификацией\n- **`context/useAuth.js`** - Hook для доступа к AuthContext\n- **`context/NotificationContext.jsx`** - Глобальная система уведомлений\n- **`context/useNotification.js`** - Hook для уведомлений\n\n**Преимущества:**\n- Не нужно передавать props через множество уровней\n- Лучший паттерн для глобального состояния\n- Простота в использовании\n\n---\n\n### 5️⃣ **Компоненты-обертки**\n\n#### Created:\n-
